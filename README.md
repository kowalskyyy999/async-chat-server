# Asynchronous Chat Server

A Playground project for learning asynchronous programming in Rust using Tokio.

Inspired by the [Rust Training Microsoft](https://microsoft.github.io/RustTraining/async-book/ch17-capstone-project.html) 


# Getting Started
## Run The Server
```bash
cargo run -p server
```

## Run The Client
```bash
cargo run -p client
```
